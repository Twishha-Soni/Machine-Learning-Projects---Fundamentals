# Hands-On Machine Learning (Practice & Exercises)

This repository contains my personal code implementations, exercises, and experiments from practicing with the book **"Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow (3rd Edition)"** by Aurélien Géron.

The purpose of this repository is strictly educational—to track my learning progress, master core machine learning workflows, and showcase my implementation skills.
